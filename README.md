# Currency Exchange for Pebble Watch
Currency Exchange is a Pebble app build using PebbleJS to easily keep track on currency exchange.

The app allows to add, remove and set the preferred currency so the user can compare all the currency together;

## Requirement
Pebble Tool v5.0.12
SDK: v4.5

## Build
- Follow instructions on [developer.rebble.io/sdk/](https://developer.rebble.io/sdk/)

After dependencies and pebble SDK is installed, run `pebble build` and everything should work.
